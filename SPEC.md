# ADP Comparison Tool - Technical Specification

## Overview

A beautiful, responsive React webapp that compares Average Draft Position (ADP) and Expert Consensus Rankings (ECR) across four major fantasy football platforms: **Sleeper**, **MFL**, **ESPN**, and **FantasyPros**. Deployed on GitHub Pages with automated data updates via GitHub Actions.

## Data Sources

### 1. Sleeper ADP
- **Endpoint**: `https://api.v2.sleeper.app/v1/public/nba/draft/adp` (NFL equivalent)
- **Auth**: Public API, no authentication required
- **Format**: JSON with player ID, ADP, draft rate
- **Frequency**: Updated daily by Sleeper

### 2. MFL ADP
- **Endpoint**: `https://www.mfl.com/adp/`
- **Auth**: Public, may require scraping
- **Format**: HTML table → parse to JSON
- **Frequency**: Updated weekly

### 3. ESPN ADP
- **Endpoint**: ESPN fantasy API or web scraping
- **Auth**: Public
- **Format**: JSON/HTML
- **Frequency**: Updated throughout draft season

### 4. FantasyPros ECR
- **Endpoint**: `https://fantasypros.com/`
- **Auth**: Public (scraping)
- **Format**: HTML → parse to JSON
- **Frequency**: Updated daily

## Data Schema

```typescript
interface PlayerData {
  id: string;              // Unified player identifier
  name: string;
  position: 'QB' | 'RB' | 'WR' | 'TE' | 'K' | 'DEF';
  team: string;            // NFL team abbreviation
  adp: {
    sleeper: number | null;
    mfl: number | null;
    espn: number | null;
    fantasypros: number | null;
  };
  medianAdp: number | null;
  bestAdp: number | null;
  worstAdp: number | null;
  adpSpread: number | null; // best - worst
}
```

## Core Features

### 1. Player Comparison Table
- Sortable columns (click header to sort)
- Color-coded ADP values (lower = better, green gradient)
- Highlight median ADP
- Show ADP spread indicator
- Sticky header and position column

### 2. Search & Filters
- Real-time search by player name
- Position filter (QB, RB, WR, TE, K, DEF, OP)
- Source toggle (show/hide each platform)
- ADP range filter (min/max)
- "Show only players with data from X+ sources"

### 3. Visual Charts
- ADP comparison bar chart (per player detail view)
- Position distribution overview
- Source reliability indicators

### 4. Responsive Design
- Mobile-first table layout
- Collapsible filters on mobile
- Touch-friendly sorting
- Horizontal scroll for table on small screens

## GitHub Actions Workflows

### update-data.yml
- **Trigger**: Schedule (daily at 8 AM ET), manual dispatch
- **Steps**:
  1. Checkout repo
  2. Fetch data from all 4 sources
  3. Normalize and merge
  4. Commit changes if data changed
  5. Push to main

### deploy.yml
- **Trigger**: Push to main
- **Steps**:
  1. Checkout, setup Node
  2. Install dependencies
  3. Build
  4. Deploy to GitHub Pages

## Testing Strategy

### E2E Tests (Playwright)
1. **Table rendering**: Players load, sort correctly
2. **Search**: Filter players by name
3. **Position filter**: Show/hide positions
4. **Source toggle**: Show/hide data sources
5. **Responsive**: Mobile layout works
6. **Sorting**: All columns sortable

### Unit Tests (Vitest)
1. Data normalization functions
2. Sorting logic
3. Filter combinations
